A small but properly structured Web API in ASP.NET Core that exposes CRUD operations for
a `User` resource. The project is written as a reference for idiomatic ASP.NET Core
controllers with dependency injection, model binding, attribute validation, OpenAPI, and
HTTP-correct responses.

## Features

- **Attribute-routed `ApiController`** with action-level documentation.
- **Constructor-injected repository** registered through the built-in DI container.
- **Data-annotation validation** (`[Required]`, `[EmailAddress]`) plus `ModelState`-driven
  `400 Bad Request` responses.
- **OpenAPI** generated by Swashbuckle and served via Swagger UI in development.
- **Proper status codes**: `200 OK`, `201 Created` with `Location`, `204 No Content`,
  `404 Not Found`, `400 Bad Request`.

## Endpoints

| Method   | Route                | Description           | Responses          |
|----------|----------------------|-----------------------|--------------------|
| `GET`    | `/api/users`         | List users            | `200 OK`           |
| `GET`    | `/api/users/{id}`    | Get user by id        | `200 OK` / `404`   |
| `POST`   | `/api/users`         | Create a new user     | `201 Created`      |
| `PUT`    | `/api/users/{id}`    | Update a user         | `204 No Content`   |
| `DELETE` | `/api/users/{id}`    | Delete a user         | `204 No Content`   |

### User schema

```jsonc
{
  "id":        12,
  "firstName": "Ada",
  "lastName":  "Lovelace",
  "email":     "ada@example.com"
}
```

`email` is required and must be a valid e-mail address; `firstName` and `lastName` are
required.

## Quick start

```bash
dotnet restore
dotnet run --project CRUD-Sample
```

Open <http://localhost:5000/swagger> to explore the API.

## Project layout

```
CRUD-Sample/
├── Controllers/
│   └── UserController.cs    # ApiController exposing /api/users routes
├── Data/
│   └── UserRepository.cs    # Storage abstraction (in-memory)
├── Models/
│   └── User.cs              # Data model with annotation-based validation
├── Program.cs               # Composition root, Swagger setup
├── appsettings.json         # Configuration
└── CRUD-Sample.csproj
```
